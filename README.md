🌍 Trippinity
The Amazon for Trips
🔗 Live Demo: https://trippinity.vercel.app/

🚀 Overview
Trippinity is a travel marketplace that enables users to discover, compare, and book curated trips from independent travel planners in a structured and secure way.

It replaces unorganized booking via Instagram and WhatsApp DMs with a trust-first, seamless platform experience.

❗ Problem
Today, curated trips are often booked through DM-based interactions, which leads to:

❌ Unclear pricing

❌ Delayed responses

❌ Lack of trust & transparency

❌ Payment uncertainty

💡 Solution
Trippinity solves this by creating a centralized marketplace where:

👤 Travelers can:
Explore curated trips

Compare itineraries and pricing

Book trips confidently

🧑‍💼 Travel planners can:
Showcase their trips

Reach high-intent travelers

Avoid manual DM-based workflows

✨ Key Features
🎥 Interactive UI (video-based trip experience)
